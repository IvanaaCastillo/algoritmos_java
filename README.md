# Algoritmos Básicos (Core)

## Descripción

Este proyecto fue desarrollado en Java para practicar conceptos fundamentales de programación, incluyendo métodos estáticos, ciclos, manipulación de Strings y lógica básica.

## Objetivos

- Crear métodos para resolver problemas lógicos básicos.
- Practicar el uso de ciclos.
- Trabajar con Strings.
- Implementar métodos estáticos.
- Organizar código utilizando clases y paquetes.
- Validar funcionalidades desde una clase principal.
